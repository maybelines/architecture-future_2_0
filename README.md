# Архитектура «Будущего 2.0»

Компания развивает медицинское, финансовое и ИИ-направления. Цель проекта — разделить их рабочие системы и запустить общую отчётность через портал самообслуживания.

| Задание | Решение |
| --- | --- |
| [Task1](./Task1/README.md) | Целевая архитектура C4, проблемы и приоритеты MoSCoW |
| [Task2](./Task2/README.md) | Домены, DFD и обоснование разделения |
| [Task3](./Task3/README.md) | Технологический радар и план перехода на год |
| [Task4](./Task4/README.md) | Учебный стенд Yandex Cloud, Terraform и результат apply |

Медицинские карты, истории болезни и результаты исследований используются в рабочих системах, но не включаются в аналитику. Terraform разворачивает небольшой учебный стенд; целевая архитектура компании описана в заданиях 1–3.
